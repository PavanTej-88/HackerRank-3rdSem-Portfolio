## Reflection

This activity helped me understand how choosing an appropriate data structure and algorithm can make a solution more efficient. I practiced matrix traversal, dynamic arrays, string processing, element-wise comparison, and frequency mapping. I also learned to consider time and space complexity instead of focusing only on whether a program produces the correct output. Using Java 15 on HackerRank gave me practical experience with solving problems under an online judge and verifying solutions against test cases. Organizing the solutions in GitHub also helped me understand how algorithmic problem-solving work can be documented as part of a technical portfolio.
